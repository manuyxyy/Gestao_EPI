
PROJETO EPISAFE - PHP E MYSQL

1. Coloque a pasta Gestao_EPI dentro de htdocs.
2. Inicie o Apache e o MySQL no XAMPP.
3. Abra http://localhost/phpmyadmin
4. Importe o arquivo gestao_epis.sql (instalação nova) ou execute
   atualizar_banco.sql (sistema já instalado).
5. Confira os dados de conexão em conexao.php.
6. Acesse http://localhost:8080/Gestao_EPI/index.php

Fluxo de acesso:
- Em "Criar uma conta" o usuário faz o cadastro, que é salvo na tabela usuarios.
- Os perfis disponíveis são: Administrador, Gestor e Almoxarifado.
- O login redireciona direto para a página principal do perfil:
  Administrador -> Painel; Gestor -> Relatórios; Almoxarifado -> Estoque.
- O Administrador acessa todas as páginas. Os demais perfis acessam
  somente as páginas da sua rotina.
- A aba Funcionários aparece apenas para o Administrador.
- A aba Suporte fica disponível para todos os perfis (contatos e perguntas
  frequentes). Edite suporte.php para alterar os dados de contato.
- O logotipo EpiSafe aparece na aba do navegador (favicon) em todas as telas.

Acesso inicial do administrador:
- E-mail: admin@episafe.local
- Senha:  Admin@12345  (troque em Meu perfil)

As senhas são armazenadas com password_hash().
